**Bug ID:** BUG-UI-001

**Module:** Responsive Layout (Mobile Safari)

**Title:** Website layout appears compressed and overlapping on Safari (iPhone)

**Severity:** Major

**Status:** Fail

**Environment:**
1) Device: iPhone (iOS – Safari browser)
2) “Request Desktop Website” disabled
3) Website: il.iherb.com
4) Languages tested: Hebrew & English

**Preconditions:**
1) Tester has an iPhone with Safari installed.
2) Stable internet connection is available.
3) Website is fully loaded.

**Steps to Reproduce:**
1) Unlock the iPhone and open the Safari browser.
2) Ensure “Request Desktop Website” is turned OFF.
3) Navigate to https://il.iherb.com.
4) Scroll down the homepage.
5) Open any category or product page.
6) Observe the layout of banners, product cards, and text content.

**Expected Result:**
1) Website should display a clean, responsive mobile layout.
2) No overlapping UI elements.
3) Banners and product cards should align in a single-column mobile structure.
4) Text should be readable and properly spaced.

**Actual Result:**
1) UI elements (stickers/banners) appear compressed and stacked.
2) Parts of the page overlap each other.
3) The mobile layout appears broken and unoptimized for Safari.
